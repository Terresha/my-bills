MY BILLS — FREE STARTER APP

Open index.html in a browser to use the app. It stores information in that browser on that device.

Credit card tracking:
- Statement balance is tracked separately from the planned payment.
- A planned payment of $0.00 is valid, including when the card has new usage.
- Monthly projections count only the planned payment, not the full statement balance.

Installment plans:
- The full remaining plan balance is tracked separately from the scheduled installment.
- Monthly projections count only the scheduled installment.

Backup: use Export Backup to save your data and Import Backup to restore it.

Limitations: this starter version does not synchronize data between devices. Browser reminders only run while the app is open and running; it cannot guarantee notifications when the browser is closed. A free static hosting option such as GitHub Pages can make the app available online, but online hosting alone does not add account-based sync or reliable background reminders.
